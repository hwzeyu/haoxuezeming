# 费曼精读协议

方法依据：费曼四步 + smart-learn 五步闭环（概念地图→费曼解释→自测→关联→总结）+ doubao-learn-to-remember（《如何记住你读过的一切》方法论）+ reading-pipeline 的 RQ 聚焦与 Differential Value。

## 步骤 0：前置评估分诊（可选，仅在用户表明已有基础时触发）

**触发**：用户说"这本书我已经了解 X 部分""XX 我比较熟""跳过基础直接讲进阶"等。
**不触发**：用户直接说"精读这本书"未带基础说明 → 跳过本步骤，从步骤 ① 开始。

执行：
1. 仍先生成完整概念地图（保证知识结构完整）
2. 展示后询问："你对哪些概念已经比较熟悉？"
3. 为每个概念打掌握度标记：
   - 🟢 熟悉 → 步骤 ③ 只讲核心思想 + 一句话（跳过完整讲解），自测只出 1 道边界层题
   - 🟡 了解 → 步骤 ③ 正常讲但可精简，自测正常出题
   - 🔴 新手 → 步骤 ③ 完整讲解，自测从最合适层出题
4. 即使"熟悉"的概念仍写入笔记与卡片（保证完整性），讲解加速不省略记录
5. 若用户在某概念自测答错，自动降级为 🔴 并完整补充

## ① 预览定位（80/20 + RQ 聚焦门）

- 通读目录、摘要、结论，输出"大局概述"（2~3 句）
- **RQ 聚焦门（借鉴 reading-pipeline L1）**：先明确 3~5 个阅读意图问题（把章节标题改写成问题）；高产出章节（核心论点/关键机制/反直觉结论/可复用清单）与意图问题强相关的深度精读，弱相关章节只做层1速览并标注「速览」，与意图问题完全无关的章节标「跳过」并说明理由——不漫无目的通读
- 输出阅读意图问题清单（供后续自测锚定）

## ② 三层渐进笔记

- 层1：每节用自己的话记要点（≤原文 20%，逐条一句）
- 层2：从层1挑最关键的 15%（高亮中的高亮）
- 层3：一页纸执行摘要（核心思想 / 结构 / 可带走的一句话结论）

## ③ 费曼讲解（含掌握度分诊）

- 每个核心概念写一段"讲给 12 岁孩子听"的大白话；按步骤 0 掌握度调整深度（🟢 只讲核心思想+一句话 / 🟡 精简 / 🔴 完整五维：为什么需要→核心思想→类比→示例→一句话）
- 讲不通处标记「待回读」，回原文补齐后才继续
- 每条讲解记录对应章节/页码（强制溯源）

## ④ 自测与联结（三层递进自测，借鉴 smart-learn）

**递进式自测**：每个概念出 1 道题，从三层中选最合适的一层，**每次只出一道题**：

| 层次 | 考察目标 | 适合什么概念 |
|---|---|---|
| 理解层 | 改变条件问变化 | 核心机制类 |
| 应用层 | 新场景设计方案 | 可操作/方法类 |
| 边界层 | 什么时候失效 | 理论约束类 |

用户作答后给出：点评（具体哪里好/哪里不足）+ 参考答案 + 掌握度（✅ 已掌握 / ⚠️ 部分掌握 / ❌ 薄弱）。

**薄弱点回顾循环**：全部概念测完后汇总薄弱点，对每个 ❌ 概念：
1. 换一个类比重新解释（不重复原版）
2. 出一道新的同层级题目
3. 作答后点评，直到掌握度变为 ✅/⚠️ 或用户说"先继续"

**跨领域联结**（保留）：每概念 ≥1 条跨领域联结："X 是 Y 原理的具体案例"。

**Differential Value（借鉴 reading-pipeline）**：精读时若图库中已有同主题/同 cluster 的已读书，写 head-to-head 对比：解决的是同一个问题吗？哪些经验可直接迁移？本书有何独特性？并写入精读笔记「跨书对比」节。若为首本则标「baseline」。禁止空泛赞美（"经典""全面"等）。

**可选**：Q&A 闪卡（术语定义 / 机制步骤 / 关键数字 / 人物观点 / 清单）。
