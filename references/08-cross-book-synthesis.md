# 跨书概念聚合规范（多源概念页）

依据：借鉴 reading-pipeline L3 概念聚合 + 求同存异（Convergence/Divergence）+ 5-tag 合并分类法。目标：让第 N 本书**强化**而非重置已有知识——同一概念多本书相遇时自动汇聚成多源概念页。

## 触发

- 生成卡片前，先检查图库/卡片库中是否已有同主题书籍或同名概念（见「查重」）
- 已存在相关概念 → 走本规范聚合，而非新建独立概念页
- 用户明确要求"跨书综合/求同存异/把这几本书的概念汇总"时直接执行

## 查重（写卡片前必做）

- 用 Glob/Grep 扫描图库 `pages/` 与 `03-卡片/`：概念名 + 别名（**中英文变体都查**，如 `反脆弱` 与 `antifragile`）
- 命中同义概念 → `merge_into_concept`（合并进既有概念页），禁止分叉
- 未命中 → 新建概念页并登记到跨书索引

## 多源概念页结构

概念页随书增多**原地升级**为多源概念页（不另起新页）：

```markdown
# 概念-概念名.md

- card-type:: concept
- sources:: [[《书A》]] · [[《书B》]] · [[《书C》]]（按时间追加）

### 核心定义 #card
- 一句话定义（多书共识版）

### 求同（Convergence） #card
- 各书一致的观点/机制（每条标注来源书）

### 存异（Divergence） #card
- 各书冲突/侧重不同的观点（每条标注来源书与差异点）

### 综合（Synthesis） #card
- 你的判断：如何调和分歧 / 哪个视角更适用 / 适用边界
```

**硬规则**：
- 存异表**禁止静默抹平分歧**——每个分歧独占一行，标注双方观点与来源
- 综合区不能为空（空综合 = 噪声）；无法下判断时标 `status: draft` 待补

## 5-tag 合并分类法（新书并入既有概念时）

合并新书贡献时，为每条贡献打上合并标签，写进概念页对应区：

| 标签 | 含义 |
|---|---|
| SUPPORTS | 支持既有观点（追加证据） |
| REFINES | 精化/修正既有表述 |
| CONTRADICTS | 与既有观点冲突 → **触发人工复核标记**，不得静默覆盖 |
| NEW (sub-aspect) | 既有概念的新侧面 |
| NEW (concept) | 全新的子概念 → 建议另建子概念页 |

## Differential Value（精读阶段联动）

精读新书时（见 02-feynman.md ④），若存在同 cluster 已读书：写 head-to-head 对比（解决同一问题？哪些经验迁移？本书独特性？）——对比结论直接成为多源概念页「存异/综合」区的素材。首本书标「baseline」。

## 检索与维护

- 概念页沿用 `book::` 与新增 `sources::` 属性，检索时 `sources::` 命中即返回多书视角
- 每季度（或积累 ≥3 源后）复查概念页：合并新读、刷新综合、清理过期分歧
