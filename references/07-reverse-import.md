# 图库反向整理规范（Logseq → 卡片/导出）

依据：借鉴 slipbot `logseq-importer`（jrswab/slipbot）的属性映射与嵌套上下文富化机制，改写为适用于本技能"从用户 Logseq 图库整理既有笔记"的反向通道。

## 触发场景

- 用户说「整理我的 Logseq 笔记」「把我的页面做成卡片」「导出这本书的笔记」「第二大脑整理」等
- 输入：图库 `pages/`（或 `journals/`）下用户指定的页面文件
- 产出：整理后的独立卡片（复用 `scripts/make_card.py` 的卡片格式）或回写图库

## 解析流程

Logseq 页面 = 两部分：

**① 页面属性区**（页首 `key:: value`，到第一个 bullet 为止）：

```markdown
type:: #literature
source:: Book
author:: 作者
title:: 书名
tags:: #tag1
```

**② bullet 树**（大纲列表，可嵌套）：

```markdown
- 第一条笔记
- 第二条 [[双链]] 笔记
  - 嵌套子块
- 第三条 id:: abc123-uuid
```

## 属性 → 卡片来源映射

| Logseq 属性 | 映射到卡片字段 |
|---|---|
| `title::` | 卡片/书页标题 |
| `source::`（纯文本如 "Book"） | 来源类型 |
| `source:: [文本](url)` | 来源标题 + 来源 URL（markdown 链接拆成两部分） |
| `author::` | 作者（写入 `author::` 属性） |
| `type:: #literature` | 类型提示（映射为 card-type） |
| `alias::` / `status::` | 忽略 |
| `tags::` | 保留为卡片 tags（与脚本生成保持一致） |

空属性（如 `author::` 无值）→ 置空，不编造。

## 嵌套 bullet 上下文继承（核心机制）

每个**顶层 bullet** 展开为一张独立卡片；**嵌套子块**展开时把全部祖先内容拼接进内容，递归任意深度，保证上下文不丢失：

- 父：`- [[Fleeting Notes]]: 随处记的快速笔记`
- 子：` - 可以写在纸上或手机里`
- 展开结果：「Fleeting Notes (随处记的快速笔记) 可以写在纸上或手机里」

规则：
- 祖先上下文用括号或自然语拼接，放在子内容前
- 多层嵌套逐级继承（祖→父→子全部拼入）
- 一张卡片只承载一个原子想法；父子各自成卡，但子卡必带完整祖先语境

## 清洗规则（借鉴 slipbot）

展开前从每个 bullet 剥离系统噪声：

- `id:: uuid` → 删除（块 ID 不进入卡片）
- `block-tags:: #xxx` → 整段删除
- inline `#tag` → 默认删除（卡片标签由生成时统一指定）；用户要求保留时除外
- 畸形/嵌套标签（如 `#{"{`）→ 删除
- `## Citation:` 引用区 → 忽略（与属性冗余）
- 非 bullet 内容（标题、段落）→ 忽略

保留项：
- `[[双链]]` → 转为卡片关联（潜在链接目标），作为 `- 关联：` 二级子块
- markdown 格式（加粗/斜体/行内代码）→ 原样保留

## 产出与落库

- 整理结果复用 `make_card.py` 的卡片格式（属性区 + `### 标题 #card` + 树形答案）
- 输出到 `03-卡片/`（或回写图库 `pages/`），同样遵循入库前确认与断链校验
- 来源元数据（来源类型/书名/作者）随卡片保留，供检索追溯

## Edge Cases

- **无属性**：作为无来源的独立笔记处理
- **无 bullet**：报告「没有可整理的内容」
- **纯引用页**（只有双链）：转成关联清单
- **多双链**：同一 bullet 内多个 `[[ref]]` 全部保留为潜在链接
